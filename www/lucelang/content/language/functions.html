A function call looks like one operation in Luce. Underneath, arguments need storage, the runtime protects call depth, a result needs a destination, and every exit must clean up what the frame owns.

The declaration contract

A signature fixes parameter order, labels, types, trailing folded defaults, result shape, and fallibility. Omitting the result arrow means no result. -> T! declares recoverable failure; -> (A, B) returns several values directly through the call convention.

Arguments are planned before the call

  1. Select the callableNamed function, static member, bound method, lambda, closure, interface slot, or union constructor.
  2. Match labels and positionsCalls may begin positional and switch once to named arguments; duplicates and omissions are refused.
  3. Fill defaultsTrailing declaration-time constants provide omitted argument values.
  4. Evaluate in source orderWritten argument order determines the order of side effects.
  5. Apply value/reference passingValues copy; references retain the same identity for the callee.

One function-value representation

func(T, ...) -> R describes a function value. A named function carries code. A bound method adds its receiver. A block closure adds an ARC environment. All use the same indirect-call shape and can live in locals, fields, optionals, unions, and supported containers. Their process-local code and environment identity defines the boundary for comparison and worker transfer.

Methods and implied self

An instance method has an implied self. Semantics infers whether it writes the receiver. A class method mutates shared identity through a stable binding. A writing struct method requires a mutable bare local so the changed value can be written back. A static function has no receiver and behaves like a namespaced function.

Several answers are a shape

Multiple results use a call-boundary convention. A destructuring binding or parallel assignment receives every component, and a discard can ignore one. The compiler can therefore write results directly into caller-provided result slots.

Closures add an environment

(x) -> expression is capture-free. A block func(x): may capture. Immutable values snapshot, references capture strongly, mutable locals share one cell, [weak name] captures a zeroing optional, and [copy = expression] evaluates one creation-time snapshot.
