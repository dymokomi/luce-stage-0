How to inspect any feature

The rule beneath the surface

Values copy. References share identity. ARC keeps references alive. Weak references break cycles. Resources close at the last strong release. Workers communicate by copying values between separate heaps.

This rule predicts behavior across arguments, returns, fields, optionals, unions, interfaces, closures, containers, and tasks. Each feature applies the same ownership model to a different kind of storage.

Static decisions, dynamic consequences

Compile time

Every expression has one type. Calls, labels, visibility, conformance, mutation, worker transfer, possible errors, capture kind, and return coverage are decided before MIR.

Run time

Checked arithmetic may trap, references retain and release, virtual interface slots dispatch, containers enforce bounds, resources touch the host, and workers copy graphs.

How the feature set shapes the implementation

Conversions are explicit calls, conditions use bool, structs carry values, classes carry identity, ARC manages references, and workers exchange copied values. These choices determine the type checker, MIR vocabulary, runtime data structures, and generated checks. The decisions section follows those consequences in detail.
