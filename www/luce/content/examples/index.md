# Luce by example

Complete programs, one idea at a time. Each sample was checked by the
freshly built toolchain when this page was built. Runnable examples
were executed and their shown output is what they actually printed;
expected traps, raises and refusals were checked as those outcomes.

Copy any of them into a file and run `loom luce thatfile.luc`.

If you want the ideas explained rather than shown, read
[the tour](/tour/) instead; if you want the exact rules, read
[the reference](/ref/).
