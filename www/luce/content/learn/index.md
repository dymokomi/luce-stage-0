# Learn Luce

Learn is a calm first walk through the language. You will write a small
program, compile it into a native executable, and then add one idea at a
time: values, control flow, functions, data, ownership, failures, modules,
host effects, and workers.

You need basic programming experience, but no Luce experience. Read the
chapters in order if this is your first Luce program. Every example is a
complete program that you can copy, change, and build; the site checks the
examples and their expected output as part of each release.

Begin with [Hello, Luce](hello/). Once the shape of the language feels
familiar, use the [Guide](/guide/) for a whole theme or an exact rule.
