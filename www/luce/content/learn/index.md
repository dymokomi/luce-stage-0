# Learn Luce

Learn is a guided first pass through Luce. It starts with a small
program and adds one idea at a time: values, control flow, functions,
data, ownership, failures, modules, host effects, and workers.

You need basic programming experience, but no Luce experience. Read the
chapters in order if this is your first Luce program. Each runnable
example is a complete program. The site builds the examples and compares
their output (or their expected diagnostic) with the text shown here.

Start with [Hello, Luce](hello/). If you are looking for one exact rule,
use the [reference](/reference/); if you want the reasoning behind a design,
use the [guides](/guides/).
