What the three sites see

Every number here is counted from the web server's own access logs. There is no script on any page, no cookie, and nothing is sent to anyone else — which is also why installs are visible at all: curl … | bash is not something a browser tracker can see.

People a day

One person, one site, one day — so someone who reads two of these sites appears on both lines here, while the People figure above counts them once. Counted by a hash of address and browser salted with a random value made for that day and destroyed when the day closes, so the count survives and the means of recomputing it does not. Crawlers and scanners are identified and left out.

Installing Luce

Two different things, kept apart on purpose. The install line is install.sh being fetched — anyone who ran the command on the front page. An install is the toolchain archive actually being downloaded, which only happens once the script has decided the machine is one it supports.

Everything that knocked

Every request the three sites answered, people and machines alike. Most of it is neither: scanners looking for someone else's software, and crawlers doing their job.

Counted by www/stats in the LuciaOS repository: the collector reads Caddy's access logs on the one server these sites are served from, keeps per-day counts in SQLite, and writes the file this page draws. No addresses are stored.

IP geolocation by DB-IP. Days are UTC.
