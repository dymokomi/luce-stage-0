# Support

Start with the current documentation at
[luce.luciaos.com](https://luce.luciaos.com), especially the Tour, Guide,
Tools, Library, and Status pages. Reinstall the current release before
reporting a toolchain problem; the installer replaces the compiler, runtime,
editor, extension, and maintained packages as one checked unit.

For a reproducible compiler, installer, editor, or documentation problem,
email **dy@dymokomi.com** with the subject `[Luce support]`. Include:

- the complete output of `luce --build-info` and the operating system version;
- the smallest `.luc` source that reproduces the behavior;
- the exact command and complete output; and
- whether the same behavior occurs after a fresh install.

Questions about future features belong in design discussion, not the confirmed
bug ledger. Security reports follow [SECURITY.md](SECURITY.md) and must remain
private until coordinated disclosure.
