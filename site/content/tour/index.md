# A tour of Luce

Thirteen chapters, meant to be read in order. They assume you can
program in something and nothing else. By the end you will have
written a program that takes command-line arguments, builds a map,
handles a file that would not open, and gives its memory back.

Every sample here is a whole program. You can copy any of them into a
file, run `loom luce thatfile.luc`, and get exactly the output printed
underneath it — that is checked when this site is built, not claimed.

If you already program in Luce, the [guides](/guide/) go deeper on the
parts that are unusual and the [reference](/ref/) is where the exact
rules live.
