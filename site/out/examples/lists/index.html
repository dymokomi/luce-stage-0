Lists

A list(T) is a growable sequence. A literal infers its element type; an empty literal needs an annotation.

find answers -1 when the value is absent, which is a wart the status page admits: long? exists now and the sentinel has nothing holding it up.

Slices copy#

xs[a:b] allocates a new list, owned by whoever receives it. Open ends default to the beginning and the end.

Lists of lists#

A container always owns its object elements, so putting a named list into another one needs give or copy.

pop() hands an element out — the receiver owns it — while remove, clear and overwriting an element free the old one right away.
