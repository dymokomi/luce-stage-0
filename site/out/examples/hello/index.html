Hello and arguments

The smallest useful program: main, print, and a string.

The command line reaches a program as main's parameter. Declare it and it is an ordinary list(string); leave it out and the program says nothing about arguments it never reads.

Arguments arrive as strings. Turning one into a number is parse_int, which answers an long? because the text may not be a number at all — else supplies the fallback.
